Reporting a vulnerability

Report vulnerabilities privately, either through GitHub private vulnerability reporting (Security tab, "Report a vulnerability") or by email to mohammad.siavashi@outlook.com. Do not open a public issue.

Include a description, the affected version, and steps or input to reproduce. You will receive an acknowledgement, and a fix will be coordinated before public disclosure.
